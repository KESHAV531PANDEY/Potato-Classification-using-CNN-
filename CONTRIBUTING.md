# Contributing

Thanks for contributing to the Potato Disease Classifier.

## Before opening a pull request

1. Create a focused branch from `master`.
2. Keep datasets, model artifacts, secrets, logs, and dependency folders out of commits.
3. Run the backend syntax check and frontend production build.
4. Update the README when setup or API behavior changes.

## Pull requests

Use a clear title and describe the motivation, implementation, and validation performed. Include screenshots for visible frontend changes and note any model or data changes explicitly.

## Issues

For bugs, include reproducible steps, expected behavior, actual behavior, and relevant browser or API logs. Do not include private images, credentials, or other sensitive information.
